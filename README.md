# 🏦 BankAccount — Python OOP Practice

A beginner-friendly Python project demonstrating core OOP concepts
through a simple Bank Account system.

## 📁 Project Structure

BankAccount/
├── bank_account.py      # Parent class
├── savings_account.py   # Child: interest feature
├── loan_account.py      # Child: loan feature
├── main.py              # Run this to see demo
└── README.md

## 🧠 Concepts Covered

- Class & Object
- Inheritance & super()
- Dunder methods — __init__, __str__, __repr__, __add__
- Method overriding
- Encapsulation (_history)

## ▶️ How to Run
python main.py
